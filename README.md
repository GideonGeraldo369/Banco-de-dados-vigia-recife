#vigia-recife
O banco de dados do Vigia Recife utiliza PostgreSQL e estrutura-se em torno de entidades como **Espaço Público** (locais monitorados), **Usuário** (cidadãos e servidores), **Indicador Preventivo** (para o Pulso do Recife), **Ocorrências** (relatos de problemas) e **Ações Preventivas** (gestão de respostas da prefeitura).
